## 📹 Тест с реальной камерой

### Подготовка:
1. Найдите изображение оружия (нож, пистолет)
2. Можете открыть на телефоне или распечатать

### Процедура:
1. **Запустите backend** (см. Шаг 1 выше)
2. **Войдите в приложение** как охранник
3. **Перейдите в School Safety**
4. **Выберите "Main Entrance Camera"** (это ваша веб-камера)
5. **Покажите изображение оружия перед камерой**
6. **Подождите 2-3 секунды**

### Что должно произойти:

- 🚨 Красный алерт появится мгновенно
- 📸 Кадр с оружием сохранится
- 🔔 Уведомление придет всем охранникам
- 💾 Инцидент запишется в базу

## Если не работает

### Backend не запускается:
```bash
pip3 install -r apps/backend/requirements.txt
```

### Приложение не подключается:
1. Убедитесь что backend работает (смотрите терминал)
2. Проверьте URL: должен быть `http://127.0.0.1:5001`

### Уведомления не приходят:
1. Убедитесь что вошли как **Guard** (не Student!)
2. Проверьте что WebSocket подключен (в логах Flutter)
3. Перезапустите backend и приложение
