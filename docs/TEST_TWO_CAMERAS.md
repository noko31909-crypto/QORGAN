# 🚀 Qorgan: Локальное тестирование на 2 камерах

Эта инструкция поможет вам протестировать систему прямо на вашем компьютере, подключив две камеры (например, две USB веб-камеры или одну веб-камеру и одну IP-камеру).

---

## Шаг 1: Подготовка

Убедитесь, что у вас установлены:
- **Python 3.10+**
- **Node.js 18+**
- **Git**

---

## Шаг 2: Установка

Откройте терминал (или PowerShell на Windows):

```bash
# 1. Скачиваем код
git clone https://github.com/noko31909-crypto/QORGAN.git
cd QORGAN

# 2. Устанавливаем зависимости
# Windows:
pip install -r apps/backend/requirements.txt
npm install --prefix apps/web

# Linux / macOS:
./scripts/setup.sh
```

---

## Шаг 3: Настройка на 2 камеры

Создайте файл `.env` в папке `apps/backend`:

```bash
cp apps/backend/.env.example apps/backend/.env
```

Откройте `apps/backend/.env` и измените следующие строки:

```env
# Включаем демо-режим для быстрого старта
DEMO_SEED=1
QORGAN_PROFILE=dev
ENABLE_DETECTION=1

# Настройки для локального теста (2 камеры)
DETECTION_MAX_CAMERAS=2
DETECTION_MAX_WORKERS=2
DETECTION_FRAME_SKIP=1
DETECTION_MEMORY_LIMIT_MB=2000
```

*(Сохраните файл: Ctrl+O, Enter, Ctrl+X)*

---

## Шаг 4: Запуск сервера

Откройте **первый терминал** и запустите бэкенд:

```bash
cd apps/backend
python app.py
```

Сервер запустится на порту `5001`.

---

## Шаг 5: Запуск веб-интерфейса

Откройте **второй терминал** (не закрывая первый) и запустите веб:

```bash
cd apps/web
npm run dev
```

Веб-интерфейс запустится на `http://localhost:5173`.

---

## Шаг 6: Подключение камер

1. Откройте браузер и перейдите на `http://localhost:5173`.
2. Войдите под демо-аккаунтом:
   - Email: `demo.guard@qorgan.local`
   - Пароль: `DemoPass123`
3. Перейдите в раздел **School Safety**.
4. Вы увидите список камер (они создадутся автоматически благодаря `DEMO_SEED=1`).

**Чтобы подключить свои камеры:**
1. Остановите демо-камеры (кнопка `Stop`).
2. В поле камеры введите ID вашей камеры:
   - Для первой веб-камеры: `0`
   - Для второй веб-камеры: `1`
   - Для IP-камеры: `rtsp://admin:password@192.168.1.100:554/stream`
3. Нажмите `Start`.

---

## Шаг 7: Тестирование детекции

Чтобы проверить, как работает детекция оружия:

1. Запустите камеру (кнопка `Start`).
2. Покажите камере изображение ножа или пистолета (можно найти в интернете и показать с экрана телефона).
3. Система должна:
   - Обвести объект красной рамкой на видео.
   - Отправить уведомление в веб-интерфейс.
   - Сохранить кадр в папку `data/detection_images/`.

---

## 🛑 Если что-то не работает

**Камера показывает черный экран:**
- Убедитесь, что ID камеры правильный (`0`, `1` или RTSP ссылка).
- Закройте все другие программы, которые могут использовать камеру (Zoom, Skype, OBS).

**Ошибка: Port 5001 is already in use:**
- Найдите процесс, использующий порт 5001, и завершите его.
- Windows: `netstat -ano | findstr :5001`, затем `taskkill /PID <PID> /F`
- Linux / macOS: `lsof -i :5001`, затем `kill -9 <PID>`

**Нет детекции (объекты не обводятся):**
- Убедитесь, что файл модели `models/best.onnx` существует.
- Проверьте, что `ENABLE_DETECTION=1` в файле `.env`.
