# Полный гайд для запуска и защиты проекта

Этот гайд объясняет простыми словами, как работает система детекции оружия, как подключить камеры школы, как скачать код с GitHub, и как подготовиться к защите проекта.

---

## 1) Что это за система и как она работает

- **Цель:** автоматически обнаруживать оружие (пистолеты, ножи) на видео с камер.
- **Модель:** используется YOLOv8 — современная нейросеть для детекции объектов.
- **Сервер:** на Python (Flask). При обнаружении оружия сервер сохраняет кадр и отправляет уведомление в приложение.
- **Мобильное приложение:** на Flutter (iOS/Android). Показывает уведомления, список инцидентов и экран камер.

### Поток данных (простыми словами)
1. Камера даёт видео.
2. Сервер (YOLOv8) анализирует картинку.
3. Если видит оружие — сохраняет кадр и создаёт «инцидент».
4. Через WebSocket отправляет сигнал в приложение.
5. Приложение показывает алерт и сохраняет уведомление.

## 5) Подключение камер школы (варианты)

Есть два варианта: быстрая проверка с веб-камерой и подключение IP-камеры школы.

### Вариант A — Быстрый тест с веб-камерой (локально)

```bash
# Просто показать детекцию на веб-камере (без мобилки)
python3 tools/vision/camera_test.py
```

- Откроется окно, модель будет рисовать рамки на видео.
- Нажмите `q` чтобы закрыть.

### Вариант B — Интеграция камеры с backend

Backend автоматически создаёт «камеру по умолчанию» (веб-камера `0`).
Чтобы использовать конкретную RTSP-камеру школы, запустим детекцию прямо из кода:

1. Откройте файл `apps/backend/app.py`.
2. Найдите самый низ (там где создаётся камера по умолчанию).
3. Добавьте запуск детекции (пример):

```python
# ВНИЗУ app.py (после создания default_camera)
from pathlib import Path

with app.app_context():
    # Если хотите запустить детекцию на веб-камере:
    detection_service.start_camera_detection(
        camera_id='main_entrance',
        camera_source='0',                # 0 = вебкамера
        camera_location='Main Entrance'
    )

    # Пример для IP-камеры по RTSP:
    # detection_service.start_camera_detection(
    #     camera_id='school_cam_1',
    #     camera_source='rtsp://user:pass@192.168.1.50:554/Streaming/Channels/101',
    #     camera_location='School Main Hall'
    # )
```

4. Перезапустите backend:

```bash
cd apps/backend
python3 app.py
```

> Форматы RTSP разных камер отличаются. Примеры:
> - Hikvision: `rtsp://user:pass@IP:554/Streaming/Channels/101`
> - Dahua: `rtsp://user:pass@IP:554/cam/realmonitor?channel=1&subtype=0`
> - Uniview: `rtsp://user:pass@IP:554/live/1/0`

Если всё ок — при обнаружении оружия backend сохранит кадр в `data/detection_images/` и отправит уведомление в приложение.

## 7) Как защищать проект (что показать и рассказать)

### Демонстрация (пошагово)
1. Показать структуру проекта: `ARCHITECTURE.md` и папки `apps/`, `data/`, `docs/`.
2. Запустить backend и мобильное приложение (из раздела «Запуск»).
3. Открыть экран камер в приложении.
4. Показать распознавание (веб-камера с распечаткой ножа/пистолета или RTSP-камера).
5. Показать уведомление в приложении и кадр в `data/detection_images/`.
6. Открыть список инцидентов — показать запись с временем и уверенностью модели.

### Что сказать (ключевые пункты)
- Мы используем YOLOv8, потому что она быстрая и точная для детекции объектов.
- Сервер на Flask обрабатывает детекции и отправляет уведомления в реальном времени.
- Мобильное приложение на Flutter получает события и показывает интерфейс охранникам.
- Все данные (кадры, логи) сохраняются структурированно в `data/` и `logs/`.
- Есть автотесты: имитация уведомления и детекция по изображению для быстрой проверки.

### Вопросы-ответы (FAQ)
- **Что, если камера не подключается?** Проверьте RTSP-URL, логин/пароль и сеть. Попробуйте веб-камеру `0`.
- **Где лежит модель?** В `models/best.onnx`. Можно заменить на другую (с тем же именем).
- **Как поменять порты/секреты?** В `apps/backend/app.py` (параметры Flask/SocketIO), добавьте `.env` при переносе в прод.
- **Можно ли добавить ещё камеры?** Да, запустите `detection_service.start_camera_detection()` для каждой.
