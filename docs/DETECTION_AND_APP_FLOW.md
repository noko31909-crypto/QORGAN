# Детекция оружия/ножей и уведомления в приложении

## Смысл проекта

В приложение должно приходить уведомление при детекции оружия или ножей с высокой вероятностью. Детекция **не отдельна** от приложения — она встроена в бэкенд и при срабатывании сразу пишет в БД и шлёт события в приложение.

---

## Как это устроено

### 1. Детекция (бэкенд)

- **Файл:** `apps/backend/detection_service.py`
- **Модель:** YOLO (`models/best.onnx`), классы — то, что обучено в модели (оружие, ножи и т.д.).
- **Порог:** `confidence_threshold=0.5` — при уверенности ≥ 50% считается срабатывание.
- При срабатывании вызывается колбэк `on_weapon_detected` в `app.py`.

### 2. Что делает бэкенд при детекции (`app.py` → `on_weapon_detected`)

1. **Инцидент в БД** — создаётся запись `Incident` (тип `weapon_detected`), сохраняются класс, уверенность, локация камеры, путь к фото.
2. **WebSocket** — всем подключённым клиентам отправляется событие `weapon_alert` (в реальном времени).
3. **Уведомления охранникам** — для каждого пользователя с ролью `guard` создаётся запись в таблице `Notification`. Они видны в приложении в разделе «Уведомления» (API `GET /api/notifications`).

### 3. Как приложение получает уведомление

| Канал | Где в приложении | Когда видно |
|-------|-------------------|------------|
| **WebSocket `weapon_alert`** | Подключение в `MainScreen`; при событии показывается диалог «Оружие обнаружено» | С любого экрана главного приложения (Live, SOS, Map, Уведомления), пока приложение открыто и сокет подключён. |
| **Список уведомлений** | Экран «Уведомления» — запрос `getNotifications()` к API | При открытии раздела «Уведомления» охранник видит все сохранённые алерты (в т.ч. по детекции). |

### 4. Автозапуск детекции

При старте бэкенда после инициализации БД автоматически запускается детекция по **всем активным камерам** из таблицы `Camera` (в т.ч. камера по умолчанию с `stream_url='0'` — веб-камера). Если модели нет или камеры недоступны, сервер всё равно стартует, в логе будет сообщение вида `Detection auto-start skipped ...`.

---

## Итог

- **Функция «уведомление при детекции оружия/ножей с высокой вероятностью» в проекте есть:** детекция вызывается на бэкенде, пишет инциденты и уведомления, шлёт `weapon_alert` в приложение.
- **Детекция не отдельна от приложения:** один контур (детекция → колбэк → БД + WebSocket + Notification), приложение получает и реальное время (диалог), и историю (раздел «Уведомления»).
- **Сделано дополнительно:** автозапуск детекции по камерам при старте сервера; глобальный показ алерта об оружии с любого экрана приложения (не только School Safety).
